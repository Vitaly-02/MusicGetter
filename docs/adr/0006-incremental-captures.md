# ADR-0006: Порционный immutable capture и явная полнота

Статус: принято. Дата: 2026-10-05.

## Контекст

Виртуализированный DOM не содержит всю библиотеку одновременно; MV3 service worker может останавливаться.

## Решение

Один capture на коллекцию; bounded chunks, durable IndexedDB outbox, ACK после commit, immutable sequence replay, seal после непрерывного диапазона. Только sealed capture создаёт import jobs. Unknown end означает partial. Повторный импорт добавляет, но не удаляет.

## Альтернативы

Один большой JSON и полный in-memory snapshot не подходят большим библиотекам. Импорт до seal усложняет остановку сбора и объяснение неполных данных. Таймаут как доказательство полноты отвергнут.

## Последствия

Приём и исполнение разнесены, старт доставки позже. Resume сети надёжен; resume DOM после reload может требовать повторного прохода. Лимиты подлежат измерениям. Изменение коллекции во время сбора не даёт консистентный streaming snapshot.
