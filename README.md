# MusicGetter

Архитектурный каркас monorepo для переноса музыкальных коллекций из
Spotify, Яндекс Музыки и VK Музыки через browser extension в музыкальный
Telegram destination. Лицензия MIT.

Расширение собирает только доступные пользователю данные отрендеренной
страницы. API стримингов, перехват запросов и передача их credentials запрещены.

- [Сущности и ограничения БД](docs/database.md)
- [Протокол приёма и привязка расширения](docs/protocol.md)

- [Архитектурные решения](docs/adr/README.md)
- [Правила разработки](AGENTS.md)

В репозитории только документы и декларативные Go/TypeScript контракты.
Сервисы, extension bundle, manifest, SQL migrations и бизнес-логика отсутствуют.
Проверка Go-контрактов: `go test ./...` и `go vet ./...`.
Путь module `musicgetter` пока локальный; перед публикацией заменить на адрес
репозитория. Директива Go 1.21 соответствует доступному здесь компилятору и не
задаёт production toolchain; перед реализацией выбрать поддерживаемую версию.
